# GameJam_Sustentabilidade

Para baixar o projeto é necessario ir ate a pasta "Assets" e ir em "Build em APK" e exporta o
arquivo "BrotoBô.apk" para o seu celular, caso ja esteja no celular ou acabou de exportar para o 
celular você vai nos seus arquivos e baixa o APK no seu dispositivo movel. Logo apos instalar tudo
você deve encontrar o jogo no seu telefone normalmente.
